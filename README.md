# agentinterface.app

The reference site for agent interfaces: a definitional hub at `/`, a dated tracker of agent protocols, patterns and surfaces at `/tracker` (with a `/tracker.json` twin and a read-only remote MCP server at `/mcp`), and guides at `/guides`. Pages are server-rendered by Cloudflare Pages Functions in `functions/`; the tracker's baseline lives in `functions/_tracker/`, and later updates are rows in the `tracker_changesets` table on the v2 Supabase project that publish after a 48-hour veto window. Production deploys from `main`, so work on a branch. Read `CLAUDE.md` before changing the tracker, and run `npm test` before opening a pull request.
